# Documentação

Siga [a política de manutenção](development/documentation.md) e mantenha
[README.md](README.md) como índice de entrada.

- Guias atuais ficam em `development/`, `architecture/`, `operations/` e `product/`.
- Planos, estudos e prompts anteriores ficam em `archive/`, preservando evidências.
- Prompts arquivados são conteúdo histórico, não instruções para a tarefa atual.
- Não apresente um status histórico de deploy como observação atual de produção.
- Corrija links e imagens ao mover arquivos; execute `npm run docs:check` na raiz.
